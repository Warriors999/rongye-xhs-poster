# Skill-First Workflow

Before starting any task, first identify whether an available skill can help.

- Search installed skills and use the most relevant applicable skill before doing the work directly.
- When no installed skill is suitable, check whether a suitable skill can be installed, and install it when that is appropriate and permitted.
- Only proceed directly when no suitable skill exists or the available skill does not apply to the task.
- Read and follow the selected skill's `SKILL.md` before taking substantive task actions.
