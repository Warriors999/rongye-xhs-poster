# 绒页参考落实修订

本轮是已授权手机 UI 升级的修订。原品牌进入页、加载提示、slogan、圆点与粗体「绒页」logo 为内容和品牌保留项，不参与重设计。Pinterest 作为布局与风格参考，Apple HIG 作为交互研究参考；新生成的 2.5 影像作为装饰及灵感素材。

## 参考审阅

- Pico：https://www.pinterest.com/pin/391250286400432831/ 。2026-10-12 在已登录 Edge 重新查看。主页紧凑品牌栏、主要创作卡、最近项目列表、灵感区按优先级排列。应用：上传变首屏主视觉操作，真实最近作品独立分组，灵感卡横滑。拒绝复制紫色品牌、会员与额外工具入口。
- 图库工具：https://www.pinterest.com/pin/604045368788181850/ 。2026-10-12 在已登录 Edge 重新查看。图片是主要信息，文本轻量；工具在图片外或以透明层浮于图片。应用：作品卡减少围框，大图和紧凑底部工具；表单采用留白与分组，不以装饰横幅挤占首屏。
- Apple：https://developer.apple.com/design/human-interface-guidelines/tab-bars 。本轮重新核对：标签栏支持顶层导航、保存每个区域状态；带文字标签；图标在竖屏显示于文字上方；浮于内容上的材料背景；不把动作当导航。应用：两项稳定导航、圆角透明浮层、独立生成动作条；打开作品库时创作流程继续挂载。

## 设计与验收

原版进入页保持。功能页用 20px 手机边距、34px 大标题、17px 正文、13px 辅助文字、44px 以上点击区域。首屏只展示创作标题和上传卡。上传卡以三张本轮 2.5 图片形成微海报叠层，说明与按钮放在安全留白区；选图后显示用户原图。想法、参考图、补充信息使用白色分组面板，参考图入口为图标+说明+动作行。灵感为 160px 横滑图卡，真实最近项目以紧凑图文行展示。底部为紧凑浮动导航，生成按钮位于导航上方独立动作区域；焦点输入时隐藏导航以减少键盘遮挡，生成动作保持可用。结果大图、作品库网格、文案页统一圆角、字级和按钮。

验收：品牌组件与原版一致；390/375px 无页面横向溢出；灵感横向滚动仅发生在自身容器；主图和文本无重叠遮挡；选图/参考/只重做/下载/保存/恢复均可用；打开作品库不取消正在生成的请求；尊重减少动态及减少透明偏好；生产构建与手机 E2E 通过。真实生图差异另行验收，不改变 Render。
