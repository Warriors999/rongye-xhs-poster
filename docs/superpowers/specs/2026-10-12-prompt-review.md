# 生图前提示词确认

用户授权新增查看与编辑步骤。保持原品牌、轻量手机流程、单个Render Free Web服务。参考既有iOS分组输入与稳定双导航；新页面不生成装饰图片。主内容是方案切换与可编辑提示词。

流程：上传原图和想法 → 文字模型分析并返回三套结构化方案 → 项目规范生成可读提示词 → 查看、修改或保留 → 用户点击提交 → 原图与用户确认的提示词进入2.5 → 原有结果/下载/历史。

设计接口仅调用视觉文字模型，不调用图片模型。图片提交接口只使用已确认方案，不重新调用文字模型。主体身份与准确文字保护作为固定约束单独显示；编辑区可以修改场景、色彩、构图、字样要求，服务端限制长度并保留固定约束。页面显示将实际提交的完整提示词，编辑区不含密钥或内部服务字段。

新确认页：原图缩略图、大标题「先看看设计提示词」、三方案切换、明确的可编辑文本、恢复模型原稿、固定主体保护说明、「按当前提示词生成3张」。等待文字模型时显示独立状态。支持不修改直接提交。

待确认草稿只保存当前一份到IndexedDB单独库，包含原图、参考、输入、方案、编辑稿。完成后清除此草稿；可在上传页恢复。不自动重启或重发未知在途图片任务。已有最近12个成品库不变，仍属于同浏览器同域名，清理浏览器数据会丢失，不跨设备。Render休眠/重启可能丢失执行中的任务，草稿/已保存成品不受其影响。

Render依据：https://render.com/docs/free ，2026-10-12现场核对：15分钟无入站流量休眠；休眠、重启、部署清除临时文件；Free无持久磁盘；750小时共享；Free Postgres30天过期，因此不以其承诺长期历史。服务端队列继续内存模式。

验收：设计接口图片调用为0；确认提交视觉模型调用为0；用户编辑进入实际图片请求，原稿可恢复；空提示词不可提交；刷新草稿可恢复；失败回确认页；单张重做、作品库仍可用；手机无溢出/遮挡；本机真实三张输出并显示提示词；构建与测试。线上不部署。
