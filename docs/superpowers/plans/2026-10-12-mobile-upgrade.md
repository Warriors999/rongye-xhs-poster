# 绒页手机端升级实施计划

目标：在独立开发副本完成轻量全站 UI、参考图、单张重做、本机作品库与生成改进。技术沿用 Next.js/React/Zustand/Zod，无新增产品后端服务。

1. 生成协议：对 design-system 添加正常数字/位置/背景变化不被删除的回归测试；实现窄范围主体/事实过滤。添加参考图可选协议与多模态第二图片；更新通用参考摘要和差异提示。
2. 任务重做：GenerationJob 增加目标槽位、已有方案和改进要求；提交时引用服务器内存任务的原图，不发送密钥/大图到队列；一个任务生成一个槽位，原结果在客户端保留。添加目标隔离和失败保留测试。
3. 客户端：IndexedDB 保存作品原图、结果、输入；转换同源资产为 Data URL 后保存；最多 12 个，删除可确认；作品恢复至 choose。单张重做恢复并只合并目标图；增加提示词查看。
4. UI：统一轻量品牌导航、照片和参考输入、真实成品示例、真实生成状态、结果操作和文案页；移动分享/下载；手机优先的 CSS。
5. 验收：针对性测试→全量单测/类型检查→build→production health→手机真实页面与上传 mock 完整流/刷新作品/单张重做；必要时修复。保留未部署状态。
